ЭТАП 4. ТАЙМЛАЙН И ПЕРЕМОТКА В СЭМПЛАХ.

ЦЕЛЬ: перемотка как в плеере — по готовому звуку, без перезапуска синтеза на каждое
движение пальца, с честным временем.

СДЕЛАЙ:
1) core/SourceIndex.kt: для каждого чанка [startSample, endSample); функции
   chunkAt(sample), offsetInChunk(sample), readyEndSamples; обновляется по мере синтеза
   (готовые диапазоны могут быть фрагментированы).
2) core/ReadyMap.kt: набор готовых диапазонов + contains(sample). Источник истины —
   PcmStore (готовый чанк = есть в сторе), ReadyMap только индексы.
3) UI PlayerBar:
   - текст времени: `MM:SS / ≈MM:SS`, где первое — текущая позиция в source-сэмплах,
     второе — оценка полной длительности (по DP, помечена «≈»); если оценки нет — `MM:SS / MM:SS готово`;
   - Slider: range 0..readyEndSamples; при drag меняется ТОЛЬКО локальное состояние;
     seek выполняется один раз в onValueChangeFinished; во время drag отображаемый
     диапазон фиксируется (готовое аудио продолжает расти — ползунок не должен «уезжать»);
   - кнопки −10 с / +10 с — арифметика по сэмплам;
   - индикатор «Буферизация» при переходе в неготовое.
4) Seek:
   - внутри готового: точный старт с байтового смещения в чанке, flush, сброс PlaybackClock;
   - в неготовое: P1-задача на целевой чанк, пауза текущего звука, статус BUFFERING,
     после готовности — воспроизведение с целевого сэмпла (не с начала чанка, если
     пользователь попал в середину);
   - при быстрых повторных seek отменяй предыдущую P1-задачу (generation), не запускай
     параллельные синтезы.
5) Переход к неозвученному тексту отдельным действием: тап по абзацу → «Читать отсюда»
   (P1), ползунок при этом не используется. Это вариант 7А мастер-документа.
6) MediaSession: передавай позицию в мс и скорость, поддержи onSeekTo (маппинг в сэмплы),
   onFastForward/onRewind = ±10 с. Уведомление с прогрессом (MediaStyle).
7) DP-оценки длительности (P4): считай для следующих N чанков в фоне, кэшируй в чанке,
   не задерживай первый звук. Если DP недоступен — «≈» не показывай.

ПРИЁМКА:
- 20 перетаскиваний подряд: число запусков synthesize не больше числа отпусканий пальца
  (покажи счётчики из логов);
- seek назад мгновенный, без синтеза;
- seek вперёд в неозвученное: звук начинается именно с выбранного места (проверка по
  смещению в сэмплах, покажи расчёт);
- во время drag готовое аудио растёт, а выбранная точка не «уезжает»;
- позиция и время совпадают с фактическим звуком (проверить на 3 точках).
