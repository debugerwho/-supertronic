ЭТАП 8. ЯЗЫКИ И ИМПОРТ ДОКУМЕНТОВ.

ЦЕЛЬ: язык определяется корректно по чанку; EPUB читается в правильном порядке; PDF либо
работает на реальной кириллической книге, либо честно ограничен.

СДЕЛАЙ:
1) Языки:
   - список = официальные 31 (`en ko ja ar bg cs da de el es et fi fr hi hr hu id it lt lv nl
     pl pt ro ru sk sl sv tr uk vi`) + `na`; удали `zh` и `sr` из селектора и детектора;
   - LanguagePolicy (core/): resolve(chunkText, contextText, userChoice) →
     (code, confidence, source); правила: ручной выбор > уверенный чанк > контекст абзаца >
     ru при кириллице и неоднозначности; уверенно неподдерживаемый язык → UNSUPPORTED
     (сообщение + предложение выбрать вручную), не подменять русским;
   - для иероглифов: `ja` только при наличии каны; иначе UNSUPPORTED (не `zh`);
   - проверка code перед передачей в движок; в debug — assert;
   - детекция по чанку выполняется в фоне при планировании, результат кэшируется в чанке;
     детектор для подписи UI — по образцу ≤4000 символов.
2) Кэш-ключ синтеза (если остался): включает text, lang, voice, steps, revision модели,
   версию нормализации/детектора. Без этого — не кэшировать вовсе (после этапа 0 дискового
   кэша нет; если оставлен RAM-кэш — ключ обязателен).
3) EPUB (DocumentImporter):
   - читать META-INF/container.xml → OPF → manifest + spine → главы в порядке spine;
   - кодировка: XML declaration / meta charset; поддерживать windows-1251;
   - потоковое чтение zip-записей, без словаря всех HTML в памяти;
   - заголовок главы из <title>/<h1..h3>, иначе «Глава N»; сущности (&nbsp; и др.) раскрывать.
4) PDF:
   - приоритет: подключить PDFBox-Android (`com.tom-roush:pdfbox-android`) через Gradle,
     инициализировать и извлекать текст постранично с лимитом памяти;
   - если зависимость не резолвится/не подходит — оставить текущий экстрактор, но явно
     ограничить: сообщение «PDF без текстового слоя/с нестандартной кодировкой не поддерживается»,
     и не выдавать мусор за текст (проверка: доля букв/пробелов, длина);
   - не читать файл целиком дважды (ByteArray + String).
5) TXT: срезать BOM, определять UTF-8/UTF-16/1251, потоково; не держать две копии.
6) Тесты: ru/en/uk/смешанный ru+en/короткое «Да»/неподдерживаемый (китайский) — ожидаемые
   результаты; EPUB-фикстура с 3 главами в неверном алфавитном порядке; PDF-фикстура с
   кириллицей (текстовый слой).

ПРИЁМКА:
- grep: `zh`, `sr` в списке языков и детекторе отсутствуют;
- таблица тестов языка: вход → ожидание → факт;
- EPUB: главы в порядке spine (покажи список);
- PDF: реальная русская книга даёт осмысленный текст ИЛИ явное сообщение об ограничении
  (покажи, что именно);
- отсутствие ANR при импорте 5 МБ книги.
