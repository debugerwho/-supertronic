ЭТАП 3. RAM-ХРАНИЛИЩЕ PCM И НЕЗАВИСИМЫЙ ПЛЕЕР.

ЦЕЛЬ: книга читается часами без роста памяти; пауза реально останавливает вычисления;
перемотка назад мгновенная; синтез не блокируется экспортом.

СДЕЛАЙ:
1) audio/PcmStore.kt — off-heap хранилище:
   - блоки DirectByteBuffer по 4 МБ; аллокация с обработкой OutOfMemoryError;
   - append(key, pcm): Boolean (false, если бюджет исчерпан);
   - read(key): ByteArray?; readRange(key, byteOffset, length): ByteArray;
   - usedBytes(), maxBytes (настройка 64/128/256 МБ, по умолчанию 128);
   - evictOutside(startSample, endSample) — удаляет блоки вне окна;
   - НЕ используй ByteArray размером с книгу и не держи карту всех чанков в куче.
2) audio/PcmRing.kt — окно: 45 с позади playhead, опережение до N минут (настройка 5/10/20,
   по умолчанию 10), ограничение бюджета; при заполнении синтез приостанавливается
   (backpressure), а не вытесняет нужное.
3) audio/PlaybackClock.kt: positionSamples (с учётом flush), framesSinceFlush,
   bufferedSourceSeconds (делить на speed для wall-clock), сброс при flush.
4) audio/AudioTrackSink.kt: запись слайсами ≤100 мс с проверкой отмены между слайсами,
   playbackSpeed через PlaybackParams (pitch 1.0), sample rate из конфига модели (не 44100
   жёстко). Никаких Write BLOCKING на весь чанк.
5) audio/SynthesisScheduler.kt — приоритеты P0 (нужно сейчас), P1 (цель перемотки),
   P2 (опережение), P3 (экспорт), P4 (DP-оценки). Один рабочий поток синтеза. Правила:
   P3 выполняется только при пустых P0–P2; при появлении P0 текущая P3-задача ставится
   на паузу между чанками (не убивается посреди инференса); отмена — по generation.
6) ReadSession (domain/ReadSession.kt) — оркестратор: play/pause/stop/seek, состояние
   ReadState (status, chunkIndex, positionSamples, readyEndSamples, bufferedSec, rtf, error).
   pause() → пауза звука + остановка планировщика (кроме текущего чанка) + release WakeLock.
   Отдельная команда prepareAhead(minutes) продолжает синтез в паузе.
7) Сервис: один владелец ReadSession; ViewModel только вызывает команды и собирает state.
   Никаких прямых вызовов engine из UI/ViewModel.
8) Настройки бюджета и опережения выведи в «Настройки», значения сохраняй.

НЕ ДЕЛАЙ: не добавляй AAC-архив (этап 7), не меняй формулу синтеза, не трогай экспорт
кроме того, что он должен перейти на PcmStore (сам алгоритм — этап 6).

ПРИЁМКА:
- 60 минут чтения: usedBytes ≤ maxBytes всё время, RSS не растёт линейно (покажи цифры
  каждые 10 минут, если есть возможность; иначе честно «не измерено на устройстве»);
- pause на 5 минут: счётчик синтезированных чанков не растёт;
- seek назад в готовое — без вызова synthesize (лог);
- при заполнении бюджета синтез останавливается, звук не рвётся;
- тест планировщика с фейковым движком: P3 не выполняется при непустом P0.
