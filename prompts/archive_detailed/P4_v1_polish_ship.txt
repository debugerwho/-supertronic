СЕССИЯ 4 ИЗ 4. ПОЛИРОВКА, ПОСТАВКА, ФИНАЛЬНАЯ ПРОВЕРКА.

Задание на одну сессию. Новую архитектуру не вводить. Если найдены дефекты из перечня
инвариантов — исправляй их, а не переписывай проект.

ЗАДАЧИ

1) Оверлей («плавающая панель»)
Один владелец окна (service/OverlayController.kt): show/hide идемпотентны; при stop()/
onDestroy() view гарантированно удаляется; 20 циклов start/stop без WindowLeaked.
Состав панели: Play/Pause, −10 с, +10 с, Стоп, текущий абзац (2 строки), «Открыть приложение».
Никаких визуализаций/спектра. Разрешение overlay запрашивается только по действию
пользователя; при отказе — кнопка «Разрешить» в настройках, без падения.

2) Аудиотека
Список сохранённых файлов: длительность (MediaMetadataRetriever), размер, дата; Play/Pause
через сервис с аудиофокусом (пауза книги при старте трека); «Открыть в другом плеере»
(FileProvider + ACTION_VIEW, MIME audio/mp4, audio/aac, audio/wav); удаление с
подтверждением. Открытие из библиотеки не запускает синтез.

3) Настройки и диагностика (финальный вид)
Настройки: голос, шаги 2/5/10, потоки 2/4/6/8/авто, язык (авто + 31 + na), бюджет RAM
64/128/256, опережение 5/10/20 мин, битрейт экспорта 32/48/64, очистка данных, диагностика.
Диагностика: модель (URL, revision, размер по HEAD, статус SHA-256), версии AGP/Kotlin/
Compose/ORT/Media3, время загрузки модели, RTF последних чанков, PcmStore used/max,
underruns, наблюдаемые CPU, последние 20 чанков. Все цифры — фактические, без «примерно».

4) Поставка
README.md: сборка, требования, откуда скачиваются веса (≈398 МБ ONNX), лицензии
(код MIT, веса OpenRAIL-M), известные ограничения (нет привязки к ядрам в этой сборке;
эмулятор ≠ замер телефона).
NOTICE + LICENSE-MODEL: текст OpenRAIL-M и атрибуция Supertone.
Добавь gradle wrapper (gradlew, gradle-wrapper.jar) и короткую инструкцию запуска вне
AI Studio. Удали шаблонные тесты-заглушки (ExampleUnitTest/ExampleInstrumentedTest), если они
ничего не проверяют.

5) Тесты
Прогони `./gradlew test`. Добавь недостающие JVM-тесты на: сегментацию (смещения,
аббревиатуры), LanguagePolicy, PcmStore (бюджет, эвикция), SynthesisScheduler (приоритеты),
WAV/ADTS заголовки, ResumePolicy загрузки модели (Range/200/416/неполный файл), JSON-хранилище
сессии.

6) Финальная проверка по инвариантам (ничего не меняй, пока не отчитаешься)
Для каждого пункта: ВЫПОЛНЕНО / НЕ ВЫПОЛНЕНО / НЕ ПРОВЕРЕНО + файл:строка.
 1. Нет ONNX/сегментации/детекции на Dispatchers.Main.
 2. Нет записи промежуточного аудио на диск.
 3. Ровно один экземпляр движка/EngineHost; сессии ORT не создаются вне него.
 4. Все OrtSession.Result/OnnxTensor закрыты (включая цикл шагов и textEncResult).
 5. Ошибка синтеза → ERROR, не тишина и не пропуск.
 6. PCM не в Java-куче; usedBytes ≤ maxBytes всегда.
 7. Ползунок не вызывает seek на каждый кадр; seek один раз на завершение.
 8. Нет выдуманных размеров/языков/метрик; языки 31+na.
 9. Нет двух параллельных синтезов; экспорт не блокирует воспроизведение.
10. core/ не зависит от android.*; JVM-тесты проходят.
11. ViewModel не вызывает engine напрямую.
12. Позиция/документ/настройки сохраняются и восстанавливаются.
13. MediaSession отдаёт позицию и скорость; уведомление ≤1/с.
14. WakeLock держится во время чтения и отпускается во всех путях.
15. Аудиофокус: нет автовозобновления на GAIN; библиотека уважает фокус.
16. Оверлей: один владелец, нет утечек при stop.
17. Нет Firebase/Retrofit/Room/Moshi; Media3 одной версии.
18. Отчёт не содержит утверждений о производительности телефона без замера.

7) Перечень проверок для пользователя (в отчёт)
Холодный старт и первый звук (2/5/10 шагов, 2/4/6/8 потоков); 60 минут чтения с PSS каждые
10 минут; пауза 5 минут (CPU ~0, resume без повторного синтеза); YouTube/звонок во время
чтения (пауза, без самовозобновления, позиция цела); 20 перемоток назад/вперёд; экспорт
30 минут (время, размер, VLC, стыки); импорт TXT UTF-8/1251, EPUB 20+ глав, PDF с
кириллицей; авиарежим; `ls cache` после Stop; вывод наблюдаемых CPU.
