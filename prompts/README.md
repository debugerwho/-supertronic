## Порядок

1. Checkpoint в AI Studio.
2. `00_session_bootstrap.txt` → дождаться подтверждения, что правила приняты.
3. `01` … `10` — строго по одному, с приёмкой из мастер-документа (§15).
4. `11` — после каждого этапа или при сомнениях.
5. `12` — только после экспорта в Android Studio и только если замеры оправдывают.

## Уровень «thinking» Gemini 3.8 Flash

* `high` — этапы 2, 3, 6, 7, 8 (архитектура, память, экспорт, AAC).
* `medium` — этапы 1, 4, 5.
* `low` — этап 9 (косметика, тексты).

## Ключевые ограничения среды (не пытаться обойти)

* Нет NDK/CMake/native → реальная привязка к ядрам только в handoff (`12`).
* Один модуль, одна Activity, зависимости только из Gradle.
* Эмулятор AI Studio — не замер Poco M6 Pro 4G (Helio G99).
* Веса не входят в APK; скачивание по кнопке, ≈398 МБ ONNX (лицензия OpenRAIL-M).

## Быстрая проверка «всё ли идёт по плану»

После каждого этапа ответ модели должен содержать: план, файлы, сборку, тесты,
«проверено / не проверено», обновлённый `AI_STUDIO_STATE.md`. Если хотя бы одного пункта нет —
попросить заново, не принимая работу.
